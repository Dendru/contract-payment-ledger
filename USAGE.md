# Запуск

Нужен Python 3.8+ и только стандартная библиотека. Проверено на Python 3.9.5.

Из папки с заданием:

```bash
python report.py --data data --as-of 2026-11-10 --out out
```

Если в Windows команда `python` открывает Microsoft Store или не запускается, используйте:

```bash
py report.py --data data --as-of 2026-11-10 --out out
```

Параметры:

- `--data` — папка с `contracts.csv`, `works.csv`, `payments.csv`; по умолчанию `data`;
- `--as-of` — дата отчёта в формате `YYYY-MM-DD`; обязательна;
- `--out` — папка для CSV; по умолчанию `out`.

Пример:

```bash
py report.py --data data --as-of 2026-11-10 --out out
```

## Что появляется в `out/`

- `contracts.csv` — итоги по договорам и строка `ИТОГО`;
- `works.csv` — цена, состояние на дату, выплачено всего, зачтено в счёт цены, остаток, переплата по каждой работе;
- `payments.csv` — каждый платёж и причина, по которой он включён или не включён;
- `allocations.csv` — расшифровка: какой платёж на какую работу распределён;
- `warnings.csv` — смысловые предупреждения (W-23, P-8, отмена, переплата и т.п.).

CSV записываются с разделителем `;` и кодировкой `utf-8-sig`, чтобы открываться в русском Excel. Суммы — с точкой и двумя знаками после неё.

## Как читать суммы

Это четыре разных показателя, их не нужно складывать в один:

- **Остаток по действующим** (`contracts.csv`) — сколько ещё нужно заплатить за работы, которые не отменены. Это долг.
- **Переплата по работам** (`contracts.csv`) — сколько ушло сверх цен работ. Складывается из переплат по отдельным работам; по отменённой работе сюда попадает вся выплата.
- **Нераспределённые платежи** (`contracts.csv`) — общие платежи, которые не удалось разложить по работам, потому что все цены уже закрыты.
- **Переплата** (`contracts.csv`) — итог по договору: переплата по работам плюс нераспределённые платежи.

В `works.csv`:

- **Выплачено всего** — все деньги, привязанные к работе (прямые плюс из общих);
- **Зачтено в счёт цены** — сколько из них зачтено в цену работы; не больше цены;
- **Осталось оплатить** — цена минус зачтено;
- **Переплата** — выплачено всего минус зачтено.

Если по одной работе есть переплата, а по другой — долг, отчёт покажет обе суммы одновременно. Программа не переносит переплату на другую работу автоматически.

Колонки «Остаток после очереди», «Переплата после очереди», «Остаток после всех», «Переплата после всех» — это прогноз: что останется или возникнет, если очередь и платежи после даты состоятся. Прогнозные переплаты включают уже существующую переплату из колонки «Переплата» и предполагают, что очередь и будущие платежи — общие, без привязки к конкретной работе.

`allocations.csv` показывает привязку платежа к работе (полную сумму прямого платежа), а не зачёт в цену. Зачёт и переплата — в `works.csv`.

## Тесты

```bash
py -m unittest discover -s tests -v
```

Ожидаемый результат: все тесты проходят.

## Коды возврата

- `0` — отчёт построен, даже если есть предупреждения;
- `2` — структурная ошибка входных данных или неверная дата (сообщение без traceback);
- `1` — непредвиденная ошибка.

К структурным ошибкам относятся, в частности, нарушения хронологии: `paid_at` раньше `created_at`, `refunded_at` раньше `paid_at`, `paid` без `paid_at`, `refunded` без даты выплаты или возврата, `queued` с `paid_at`.

## Важно

Программа не меняет `README.md`, `data/FORMAT.md` и CSV в `data/`. Исходные данные только читаются.
